Quick Start

1

Add the dependency

Include com.bilt:pos-lib-java or com.bilt:pos-lib-kotlin in your build file via Maven Central.

2

Configure the client

Create a BiltNexoTerminalClient with your terminal's IP address, Sale ID, and POI ID.

3

Send your first payment

Call makePayment() with an amount and currency to process a card transaction.
